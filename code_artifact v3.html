內部研發與數據分析

個資假名化 (Pseudonymization)

以唯一代碼與加鹽雜湊 (SHA-256) 替換真實身分，保留關聯性 (Reversible with Key)。

  • ✓ 支援跨表 SQL / Pandas Join：相同的真實個資會產生相同的假名代碼。
  • ✓ 產出解密對照字典：金鑰字典可獨立保管，未來需要時可追溯真實顧客。
  • ✓ 適用場景：企業內部跨部門分析、AI 機器學習模型訓練、外包工程團隊開發。
對外公開與 Open Data

個資匿名化 (Anonymization)

透過高強度遮罩、地址縣市泛化與年齡級距打碎數據，徹底不可逆轉 (Irreversible)。

  • ✓ 撕毀所有個人身分標籤：去除直接識別碼，將敏感屬性級距化與泛化。
  • ✓ 完全零保留字典與金鑰：處理後連系統管理者也無法逆向追蹤回個人。
  • ✓ 適用場景：政府 Open Data 開放資料、學術期刊發表、公眾統計報告與對外數據集。

「假名化」與「匿名化」對照指南

依據歐盟 GDPR 第4條與台灣個人資料保護法規範定義

比較面向 個資假名化 (Pseudonymization) 個資匿名化 (Anonymization)
核心精神 以代碼/雜湊值替換真實身分，**保留欄位關聯性**。 透過泛化、區間化與遮罩，**徹底無法對應回個人**。
可逆性 (Reversibility) 可還原 (持有對照字典與金鑰鹽值時) 永久不可逆 (無任何還原金鑰)
跨表關聯 (Join Ability) ✅ **100% 支援** (相同真身產生相同代碼) ❌ 不支援 (個資已被打碎或泛化)
主要處理手法 代碼化 (Tokens)、加鹽雜湊 (Salted SHA-256) 年齡區間化 (30-39歲)、地址縣市泛化、數值級距
