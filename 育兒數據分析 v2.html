角色與任務：
你是一位高階前端全棧架構師與資深數據分析師。請建構一個獨立運行的單頁 Web Application (SPA)，專為「嬰兒照護與成長日誌報表」進行強大的資料解析、關鍵指標計算與多元互動式視覺化分析，風格採暖色系嬰幼兒友善介面，並支援自訂寶寶姓名/暱稱與匯出個人化報表。

輸入報表資料結構（多檔案 CSV / Excel Support）：
系統需能自動識別並合併解析以下 12 種標準護理日誌格式（例如 [寶寶姓名]_diaper.csv 或通用檔名）：
1. diaper.csv: 時間, 類型(尿濕/排便/兩者), 顏色, 備註
2. expressed.csv: 時間, 擠奶量(ml), 左側(ml), 右側(ml), 費時(分)
3. formula.csv: 時間, 配方奶量(ml), 備註
4. growth.csv: 日期/時間, 體重(kg), 身長(cm), 頭圍(cm)
5. medication.csv: 時間, 藥物名稱, 劑量, 備註
6. milestone.csv: 時間/日期, 里程碑項目, 達成狀態/進度, 備註
7. nursing.csv: 時間, 親餵總時間(分), 左側(分), 右側(分)
8. other_activity.csv: 時間, 活動類型(抬頭/遊戲/戶外), 時長(分)
9. sleep.csv: 開始時間, 結束時間, 時長(分/小時), 睡眠類型(小憩/夜眠)
10. supplement.csv: 時間, 營養品名稱(維生素D/益生菌), 劑量
11. temperature.csv: 時間, 體溫(°C), 測量位置
12. vaccine.csv: 時間/日期, 疫苗名稱, 劑次/診所, 不良反應/備註

技術與架構約束：
- 單一 HTML 檔案交付，完全無後端伺服器依賴，不安裝 Node.js / npm 或編譯建置。
- 前端函式庫純 CDN 載入：
  - Tailwind CSS ( UI 樣式，採軟調嬰幼兒暖色風格 )
  - SheetJS ( XLSX / CSV 解析引擎 )
  - ECharts ( 高效能互動圖表 )
  - Lucide Icons ( 圖示系統 )
- 100% 本機端隱私處理：所有上傳檔案僅於使用者瀏覽器內進行 Memory Parsing，嚴禁任何外傳或伺服器請求。

核心功能模組要求：
1. 多檔拖曳與自動關聯：
   - 簡潔直覺的拖曳上傳區域。
   - 依據檔名關鍵字與 Header 自動判定資料類別，上傳包含檔名前綴時自動更新寶寶暱稱。
2. 關鍵指標 KPI 卡片與設定：
   - 齒輪設定彈窗可自由修改寶寶暱稱。
   - 預設空資料狀態，可一鍵載入測試數據。
   - 每日平均總奶量、睡眠時長、換尿布次數、親餵時間、體溫警報、最新體重身高。
3. 視覺化圖表模組：
   - 奶量與親餵趨勢疊加圖
   - 尿布與便便比例圓餅圖
   - 睡眠時長趨勢圖
   - 生長曲線雙 Y 軸折線圖
   - 體溫警戒歷史線圖
4. 統合護理日誌：
   - 按時間軸進行全數據合併排序，提供 12 種分類篩選與導出 Excel 功能。
