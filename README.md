# 🚀 AI Vibe Coding 工具作品集 (AI Vibe Coding Collection)

> 本專案為 **【AI時代的專案管理師養成班】AI 協作式網站應用 MVP 實作** 之作品成果展示入口。  
> 透過 AI 協作與 Vibe Coding 模式，打造出 16 款高質感、純前端、無依賴且支援 RWD 響應式的 Web 應用程式。

---

## 🌟 專案亮點

- **🎨 現代 Cyber-Glassmorphism 視覺風格**：採用深色玻璃擬態、環境動態漸層光暈與精緻的微互動懸停特效。
- **📱 全裝置 RWD 響應式佈局**：完美適配手機（單欄）、平板（雙欄）及桌上型電腦（3~4 欄）螢幕。
- **🔍 即時搜尋與多元篩選**：
  - 關鍵字即時搜尋（支援鍵盤快捷鍵 `/` 快速聚焦）。
  - 五大領域分類篩選（商業財務、效率與資安、健康生活、遊戲與娛樂、學習成長）。
  - 網格（Grid）與列表（List）檢視模式一鍵切換。
- **⚡ 100% 純前端架構**：所有應用皆為獨立的單一 HTML 檔案，無後端伺服器依賴，可離線直接運行或快速部署。

## 🛠️ 技術架構

- **核心技術**：HTML5、Vanilla CSS3、Modern JavaScript (ES6+)
- **字型庫**：[Google Fonts](https://fonts.google.com/) (Outfit, Noto Sans TC)
- **設計規範**：Cyber-Glassmorphism、CSS Variables、CSS Grid & Flexbox、Backdrop Filter
- **架構特點**：Zero-Build（無需建置打包）、Zero-Dependency（無外部龐大框架束縛）

## 💻 本地執行方式

本專案無需任何建置步驟（Build Step），可透過以下任一方式運行：

### 方式 1：直接開啟
直接以任何現代瀏覽器（Chrome, Edge, Safari, Firefox）按兩下開啟 `index.html` 即可。

### 方式 2：使用 Python 快速架設本地伺服器
```bash
# 在專案根目錄下執行
python3 -m http.server 8080

# 接著在瀏覽器開啟 http://localhost:8080
```

### 方式 3：使用 VS Code Live Server
在 VS Code 中安裝 **Live Server** 擴充套件，右鍵點擊 `index.html` 選擇 **"Open with Live Server"**。

## 🌐 部署指南 (Netlify / GitHub Pages)

### 部署至 Netlify (極速推薦)
1. 登入 [Netlify](https://www.netlify.com/)。
2. 點擊 **"Add new site"** -> **"Deploy manually"**。
3. 將本專案資料夾直接拖拉上傳至 Netlify 頁面，幾秒內即可完成全球 CDN 上線！
